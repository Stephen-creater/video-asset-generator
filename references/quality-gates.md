# 成片质量闸门

仅在实现、渲染和交付阶段读取。

## A. 渲染前阻断项

- [ ] 已定位阿里巴巴普惠体实际文件，或用户明确批准了有商业授权的替代字体。
- [ ] 字体通过相对路径自托管，所需字重真实存在。
- [ ] 没有用户名、个人绝对路径、令牌、Cookie、私有域名或客户隐私进入源文件。
- [ ] 每段已有明确传播任务、媒介和文字策略。
- [ ] 生图中没有生成文字、Logo、水印或伪造事实界面。
- [ ] 标题与字幕不会重复表达同一句完整文案。

字体闸门失败时，不得交付含文字最终成片。

## B. 静态构图闸门

- [ ] 关键文字稳定落在安全区；顶部停驻状态避开移动端 UI。
- [ ] 运动轨迹可以出界，但关键内容不会长期停在 UI 遮挡区。
- [ ] 文字、英文单位和标点没有越出画布或内部容器。
- [ ] 边框、圆环、光斑和卡片没有遮挡文字。
- [ ] 生图主体与叠字不争抢同一视觉区域。
- [ ] 对比在遮住数字后仍可感知方向与差距。

## C. 动画与节奏闸门

- [ ] 每段只有一个主动作，动作解释关系或引导注意力。
- [ ] 出现顺序与口播一致，没有提前展示结论。
- [ ] 相邻三段至少改变媒介、景别、运动方向、色温、信息密度中的两项。
- [ ] 没有连续大量使用大字、卡片和网格。
- [ ] 高密度解释镜头后存在呼吸或空间镜头。

## D. 技术闸门

- [ ] 预检脚本无阻断项。
- [ ] HyperFrames lint 为 0 errors / 0 warnings。
- [ ] 没有 `Math.random()`、危险百分比居中或 transform 所有权冲突。
- [ ] 每段独立从 0 秒开始，没有无意义黑屏。
- [ ] 最终 MP4 分辨率、时长、帧率、编码和音轨符合要求。

## E. 视觉验收

- [ ] 已检查最终 MP4 的 25%、50%、75% 帧。
- [ ] 快速动作已补查入场结束、峰值和退场前帧。
- [ ] 使用原始分辨率查看文字边缘、容器和安全区。
- [ ] 修改字体、字号、位置、层级或动画后已重渲染受影响段。
- [ ] 自动检查结果与人工视觉检查均已记录。

## F. 可分发检查

- [ ] Skill 或模板不包含用户字体、客户素材、生成图、私有提示词和项目原文。
- [ ] 示例使用虚构名称与相对路径。
- [ ] 所有绝对路径、用户名、联系方式、密钥与内部地址已删除。
- [ ] 已查看最终归档文件列表，只有必要的 SKILL、references 和 scripts。
