# 视觉导演手册

仅在需要设计素材地图、选择媒介或突破构图时读取。

## 1. 从传播任务到视觉形式

| 任务 | 优先视觉语言 | 常见失败 |
|---|---|---|
| 记住结论 | 章节、金句、单一象征物、强停顿 | 把完整口播塞满画面 |
| 看见差距 | 共同基线、超越、速度或密度差 | 只写两个数字，没有比较动作 |
| 理解关系 | 路径、推动、分流、回流、层级 | 四个静态框加箭头 |
| 感受规模 | 纵深、重复、尺度参照、镜头推进 | 用大字号代替规模 |
| 感受速度 | 连续变形、反馈加速、轨迹拉伸 | 所有元素同时淡入 |
| 建立情绪 | 光线、空间、材质、景深、环境叙事 | 图表承担本应电影化的内容 |
| 完成转场 | 穿越、遮罩、色温变化、空间切换 | 黑场或生硬翻页 |

## 2. 生图与图形的判断

问两个问题：

1. 观众需要相信精确关系吗？需要则优先图形或真实素材。
2. 观众需要感到空间、规模或情绪吗？需要则优先生图或实景。

两者都需要时做混合版：生图建立世界，图形只标出关键证据。不要把复杂信息直接画进生成图片，因为生成文字、数字和关系不可控。

## 3. 生图提示词结构

按以下顺序写：

`主体行为 + 空间规模 + 镜头位置 + 构图与负空间 + 光线/材质 + 色彩 + 动态暗示 + 禁止项`

示例骨架：

> Vast autonomous research hall with thousands of isolated experiment chambers, high-angle vertical composition, strong depth and scale references, primary action concentrated in the lower-middle area with clean negative space above, cinematic volumetric lighting, restrained graphite and warm amber palette, subtle motion trails, no text, no letters, no logos, no UI, no watermark.

不要在通用 Skill 中固化某个题材、品牌、人物或客户风格。

## 4. 图文融合的四层结构

1. **世界层**：生图或实景，负责空间和主光。
2. **可读性层**：局部渐变、暗角、柔焦或遮罩，只处理文字背后的对比度。
3. **信息层**：标题、关键词、数字，使用真实加载的项目字体。
4. **运动层**：镜头推进、视差、光束、局部粒子；不改变信息层的基础位置。

文字不要压在图片最复杂、最亮或人脸主体区域。提示词预留负空间只是第一步，最终仍以合成后的原尺寸帧为准。

## 5. 对比的灵活构图

- 同底向上：适合竖屏数值增长。
- 前后纵深：适合代际、规模或能力跨越。
- 稀疏到致密：适合连接、吞吐、利用率。
- 拥堵到畅通：适合瓶颈、调度、优化。
- 碎片到整体：适合集群、平台、组织化。
- 旧形态被突破：适合范式变化。

保留大数字时，把它当结论层；结构变化才是证据层。

## 6. 避免素材同质化

为每段记录五个视觉属性：

`媒介 | 景别 | 运动方向 | 色温 | 信息密度`

相邻三段至少改变其中两项。不要仅通过换强调色伪装成新镜头。

可交替使用：

- 精确图形 ↔ 电影生图；
- 近景机制 ↔ 宏观空间；
- 高密信息 ↔ 无字呼吸；
- 冷色技术 ↔ 暖色人文；
- 平面运动 ↔ 纵深推进。

## 7. 文字策略示例

- 口播解释一个机制：画面只留机制节点名，使用 K。
- 章节进入“第二个问题”：完整章节标题，使用 T，并关闭同句字幕。
- 结尾有一句真正的总结：完整金句，使用 Q，并让画面围绕它停顿。
- 宏大空间已经足够说明规模：使用 N，让字幕自然承担语言。

如果动画文字与字幕表达同一句话，二选一；不要上下同时重复。
