# 虚构口播稿

过去做一个视频贴纸，常常要重新搭结构、调动画、查画面，三四十分钟之后，效果还不一定稳定。这次我们换个方法：先把已经验证过的结构做成模板，再用参数替换内容。

这是当前模板库的演示界面。证据卡、时间线、网页滚动、提问、对比和结尾钩子，都能独立调用。

新文案进来后只做三步：第一步判断信息结构，第二步替换文字和图片，第三步检查并渲染。

Anthropic 最新的记忆研究提出，Claude 内部存在一个共享的 J-space。文章进一步比较了人类工作记忆与 Claude 调取文本记忆的差异。

真正的问题是：换了一段完全不同的文案，模板还能不能保持清晰？

这次用演示数据做对比。从零制作假设需要四十分钟，结构和效果容易波动；模板复用假设需要五分钟，主体结构稳定，只调整参数。

如果你想看下一次用真实口播稿测试，评论区回复“模板测试”。
